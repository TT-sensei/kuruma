# くるまスタディ

車を題材に、算数・ことば・タイピングを楽しく学ぶ小学生向けの学習アプリです。

車を集めてレベルアップしながら、いろいろなミッションに挑戦できます。

## できること

- 車名を入力するタイピングミッション
- 車に関するたし算・ひき算・かけ算・わり算
- 式を入力して答える算数ミッション
- 英単語や漢字・ことばの意味を選ぶことばミッション
- 学習するとポイントを獲得してレベルアップ
- レベルに応じて車が開放されるくるまずかん
- 車のコレクションを確認
- 正解・不正解に合わせた音や車の演出

## ミッション

### タイピング

表示された車名を、画面キーボードまたは本物のキーボードで入力します。スペースやハイフンを省略しても判定できます。

### けいさん

車やガレージを題材にした文章問題に取り組みます。たし算、ひき算、かけ算、わり算に加えて、式を入力して答えることもできます。

### ことば

車に関する英単語や日本語の読み・意味を、選択肢から選びます。

### くるまずかん

学習でポイントを集めるとレベルが上がり、新しい車が開放されます。集めた車をタップすると名前を確認できます。

## 対象

- 小学校低学年から中学年
- 算数やことばの学習を楽しく続けたい子ども
- タイピングや車が好きな子ども

## 記録について

ポイント、レベル、開放した車、タイピングの進み具合は、使用している端末のブラウザに保存されます。
