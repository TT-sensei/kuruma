# サーキット算数レーシング

車とサーキットを題材にした、小学生向けの算数学習ゲームです。問題の答えを左右のコースから選び、正しいコースへ進むレース体験を目指しています。

## 遊び方

1. サイトを開き、「スタート」を押します。
2. 問題が表示されたら、左右に示された答えから正しいものを選びます。
3. 正解すると得点が増え、車が選んだコースへ進みます。
4. 結果を確認して、「もう一度走る」から再挑戦できます。

## 現在の実装

- サーキット、観客席、ピット、コース、車を CSS で描画
- 左右の選択肢をボタンで操作
- 正解・不正解の結果と解説を表示
- 得点表示
- スマートフォンなどの狭い画面に対応
- 動きを減らす設定（prefers-reduced-motion）に対応

## 今後の確認・改善ポイント

現在の index.html にはサンプル問題が 1 問登録されています。繰り返し遊べる学習ゲームにするには、問題数を増やし、出題順や正解判定、ゲームの終了条件などを整える必要があります。

## 対象

小学生の算数の練習を想定しています。現在のサンプル問題は、1 年生向けのたし算です。
