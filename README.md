# くるまスタディ・サーキット

GT系レーシングカーを選び、国語・算数の2択問題に挑戦する学習ゲームです。小学1〜3年生向けに、算数は計算、国語は漢字の読みを中心に問題を用意しています。

[ゲームを開く](https://tt-sensei.github.io/kuruma/)

## ゲームの特徴

- 4種類のGT風レーシングカーと、5種類のランダムコース
- 正解すると時速が上がり、まちがえると時速が下がる。道路の中央線も速度に合わせて流れます
- 時速は60 km/hから開始。最低20 km/h、最高240 km/h
- 教科を選べる：国語＋算数、国語のみ、算数のみ
- 学年の目安を選べる：1〜3年ミックス、1年、2年、3年
- 問題は基本2択。解説と得点を表示します
- キーボード操作（← / →、A / D）にも対応

## ファイル構成

- `index.html`：画面の骨組み、車・教科・学年の選択
- `css/style.css`：GT風レーシングカー4種類、コース5種類、速度表示とアニメーション
- `js/questions.js`：小学1〜3年生向けの計算問題・漢字の読み
- `js/game.js`：出題、車とコースの反映、速度、正誤判定、得点、ゴール処理
- `README.txt`：開き方と編集方法

## 問題の編集

`js/questions.js` の `questions` 配列に問題を追加します。各問題には `id`、`subject`（国語／算数）、`grade`（1〜3）、`topic`、`prompt`、`choices`（基本2つ）、`correctValue`、`explanation` を設定します。算数は数値、漢字の読みは文字列を `value` / `correctValue` に使えます。
