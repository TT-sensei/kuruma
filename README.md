# くるまスタディ・サーキット

GT系レーシングカーを選び、国語・算数の2択問題に挑戦する学習ゲームです。

[ゲームを開く](https://tt-sensei.github.io/kuruma/)

## ゲームの特徴

- 学習開始は左側、ガレージは右側の2カラム配置。狭い画面では縦に並び、レース開始ボタンが先に表示されます

- 4種類のGT風レーシングカー、5種類のランダムコース、63種類のカスタム候補
- 正解すると加速、不正解だと減速。道路中央のラインも速度に合わせて流れ、ニトロをためて任意のタイミングで発動できます
- レース中に順位表示、スタート・中盤・ファイナルの演出、5種類の有利なレースイベントがあります
- ポイントは回数制限なし。正解率62.5%以上のレースでポイントを獲得し、カラー・ステッカー・ウイング・ホイール・ライト・ルーフ飾り・エフェクトを解放できます
- 回答ボタンは問題表示後すぐには押せず、考えるための短い時間を設けています。1問につき回答は1回です
- ベストスコア、最高速度、連続正解、称号、獲得ポイント、当日のカスタム変更回数とカスタム内容をブラウザ内に保存します
- カスタム変更の確定は1日3回まで。パーツをいくつ選び直しても、最後に「確定」を1回押すと1回分を使います。選ぶだけ・変更の取り消しでは消費しません。ポイント集め・イベント付きレース・学習は何度でもプレイできます
- 国語・算数を選択可能。問題レベルは「基礎」「標準」「チャレンジ」
- 全200問。国語は交通・買い物・健康・安全・機器の利用など、生活で目にする漢字の読みが中心
- 算数は九九中心のかけ算60問。3桁のたし算・ひき算は、繰り上がり・繰り下がりがない問題を各10問
- わり算は20問。すべてあまりのない計算
- 問題は基本2択。短い解説と得点を表示
- タブレット・スマートフォンの大きなタップ操作に対応。Shiftキーでもニトロを発動できます
- 追加機能はHTML/CSS/JavaScriptとブラウザ内保存で動き、外部通信やアカウント登録は不要
- キーボード操作（← / →、A / D）にも対応

## ファイル構成

- `index.html`：画面の骨組み、車・教科・問題レベルの選択
- `css/style.css`：GT風レーシングカー4種類、コース5種類、カスタムパーツの外観とアニメーション
- `js/questions.js`：200問の問題データ
- `js/game.js`：出題、車とコース、ニトロ、レースイベント、記録・称号・ポイント管理、7カテゴリのカスタムと日ごとの変更回数管理
- `README.txt`：開き方と編集方法

## 問題の編集

`js/questions.js` の `questions` 配列に問題を追加します。各問題には `id`、`subject`（国語／算数）、`grade`（1=基礎、2=標準、3=チャレンジ）、`topic`、`prompt`、`choices`（基本2つ）、`correctValue`、`explanation` を設定します。
