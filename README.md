# サーキット算数レーシング

左右2つの答えから正しいコースを選び、全10問のレースに挑戦する小学生向け算数ゲームです。HTML / CSS / JavaScriptだけで動作し、外部ライブラリや通信を使いません。

## ファイル構成

- `index.html`：ページの骨組みと、CSS・JavaScriptの読み込み
- `css/style.css`：車・サーキット・選択肢・画面サイズ・アニメーションなどの見た目
- `js/questions.js`：問題文、2つの選択肢、正解、解説などの問題データ
- `js/game.js`：出題順、左右への配置、正誤判定、得点、レース終了、再挑戦の処理
- `README.txt`：開き方と編集方法

## 遊び方

1. [ゲームを開く](https://tt-sensei.github.io/kuruma/)
2. 「スタート」を押す
3. 左右の答えから正しい方を選ぶ
4. 全問終了後に正解数を確認する
5. 「もう一度走る」で再挑戦する

キーボードでは、← / →キーまたはA / Dキーでも選べます。

## 問題を編集する

`js/questions.js` の `questions` 配列に問題を追加します。各問題には、問題文、2つの選択肢、正解の数値、解説を設定します。選択肢の表示位置は出題時に入れ替わるため、正解がいつも左・右の同じ側になりません。1レースの問題数は `game.questionsPerRace` で変更できます。

## 見た目を編集する

`css/style.css` を編集します。色はファイル冒頭の `:root` にある変数から変更できます。車やコースの形、ボタンの位置、スマートフォン表示、アニメーションもここで調整します。

## 技術

HTML / CSS / JavaScript。外部ライブラリ不要。GitHub Pagesで公開できます。
