# くるまスタディ・サーキット

好きな車を選び、レースを楽しみながら国語・算数の2択問題に挑戦する学習ゲームです。小学1〜3年生程度の問題を収録しています。1レースは最大8問です。

[ゲームを開く](https://tt-sensei.github.io/kuruma/)

## ゲームの特徴

- 4種類の車：レーシングカー、パトカー、消防車、トラック
- 5種類のコース：グランプリ、シティ、森、海辺、ナイトコース。レースごとにランダムで選ばれます
- 正解すると時速が上がり、まちがえると時速が下がる。道路のラインの流れも速度に合わせて変化
- 時速は60 km/hから開始。最低20 km/h、最高240 km/h
- 教科を選べる：国語＋算数、国語のみ、算数のみ
- 学年の目安を選べる：1〜3年ミックス、1年、2年、3年
- 2択の問題、左右がランダムに入れ替わる選択肢、解説と得点表示
- キーボード操作（← / →、A / D）にも対応

## ファイル構成

- `index.html`：画面の骨組み、車・教科・学年の選択
- `css/style.css`：車4種類、コース5種類、速度表示、レスポンシブ表示、アニメーション
- `js/questions.js`：国語・算数の問題、選択肢、正解、解説
- `js/game.js`：出題、車とコースの反映、速度、正誤判定、得点、ゴール処理
- `README.txt`：開き方と編集方法

## 問題の追加方法

`js/questions.js` の `questions` 配列に問題を追加します。各問題には `id`、`subject`（国語／算数）、`grade`（1〜3）、`topic`、`prompt`、`choices`（基本2つ）、`correctValue`、`explanation` を設定します。選択肢の `value` が正解判定に使われ、`label` が画面に表示されます。

`css/style.css` で車やコースの色と形を変更できます。車・コースを追加する場合は、`js/game.js` の `vehicles` / `courses` の設定とCSSを合わせて変更します。
