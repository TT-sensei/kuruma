くるまスタディ・サーキット
==========================

■ このゲームについて
GT系レーシングカーで国語・算数の2択問題に挑戦します。全200問です。

■ 問題の内容
国語：交通、買い物、健康、安全、学校、機器の利用など、生活で目にする漢字の読み。
算数：九九中心のかけ算60問。3桁のたし算・ひき算は繰り上がり・繰り下がりがない問題を各10問。わり算は20問で、すべてあまりが出ません。
問題は基本2択で、短い解説が表示されます。

■ 遊び方
1. index.htmlをブラウザで開き、車・教科・問題レベルを選びます。
2. コースは5種類からランダムに選ばれます。
3. 正解すると時速が上がり、不正解だと時速が下がります。
4. 左右の答えから選びます。← / →キー、A / Dキーでも選べます。

■ ファイル構成
index.html       画面の骨組み、車・教科・問題レベルの選択
css/style.css    車4種類、コース5種類、速度に連動するアニメーション
js/questions.js  全200問の問題データ
js/game.js       出題、速度変化、正誤判定、得点、ゴール処理
README.txt       この説明書


追加したゲーム機能
・ニトロ：正解でゲージがたまり、満タンで発動できます。PCではShiftキーでも発動します。
・レースイベント：追い風スタート、ニトロデー、ポイントボーナス、クルー応援デー、連続正解フェスがランダムで発生します。
・順位表示：回答に応じてライバルとの位置が変化します。
・ガレージ：レースで集めたポイントでネオン（25pt）、レーシング（60pt）、カーボン（100pt）を解放できます。
・記録と称号：完走数、ベストスコア、最高速度、連続正解、獲得称号などをブラウザ内に保存します。
・保存データは利用中のブラウザ内に保持され、外部通信は行いません。


■ 学習と1日の遊び方
・回答ボタンは問題が表示されてすぐには押せず、問題を読む時間を設けています。1問につき回答は1回です。
・スペシャルイベントとガレージ用ポイントの獲得は1日3回までです。スペシャルレースを開始すると1回分を使用します。
・上限後も通常レースと学習は何度でも続けられます。日付は使用中の端末・ブラウザのローカル日付で切り替わります。
・日ごとの回数はブラウザ内に保存されます。ブラウザの保存データを削除すると記録もリセットされます。
・ガレージ用ポイントは、スペシャルレースで正解率62.5%以上のときに獲得できます。8問なら5問以上の正解が必要です。
