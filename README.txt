くるまスタディ・サーキット
==========================

■ このゲームについて
GT系レーシングカーで国語・算数の2択問題に挑戦します。
小学1〜3年生向けで、算数は計算、国語は漢字の読みが中心です。

■ 遊び方
1. index.htmlをブラウザで開き、車と学習する教科・学年を選びます。
2. コースは5種類からランダムに選ばれます。
3. 正解すると時速が上がり、まちがえると時速が下がります。
4. 道路の中央線は、これまでより速く流れるようにしています。
5. 左右の答えから選びます。← / →キー、A / Dキーでも選べます。

■ ファイル構成
index.html       画面の骨組み、車・教科・学年の選択
css/style.css    車4種類、コース5種類、速度に連動するアニメーション
js/questions.js  計算問題・漢字の読み・選択肢・正解・解説
js/game.js       出題、速度変化、正誤判定、得点、ゴール処理
README.txt       この説明書

■ 問題を追加・編集する
js/questions.jsのquestions配列に問題を追加します。
算数は計算問題、国語は漢字の読みを中心にし、promptに問題文、choicesに基本2つの選択肢、correctValueに正解、explanationに短い解説を設定してください。
