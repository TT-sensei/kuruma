サーキット算数レーシング
========================

■ このゲームについて
左右2つの答えから正しいコースを選び、全10問のレースに挑戦する小学生向け算数ゲームです。
HTML / CSS / JavaScriptだけで動き、外部ライブラリや通信は使いません。

■ 遊び方
1. index.htmlをブラウザで開きます。
2. 「スタート」を押します。
3. 左右の答えから正しい方を選びます。
4. 全問終了すると、正解数が表示されます。
5. 「もう一度走る」で再挑戦できます。
   キーボードの← / →キー、またはA / Dキーでも選べます。

■ ファイル構成
index.html       ページの骨組みと、CSS・JavaScriptの読み込み
css/style.css    車、サーキット、ボタン、画面サイズ、アニメーションなどの見た目
js/questions.js  問題文、2つの選択肢、正解、解説などの問題データ
js/game.js       出題順、左右への配置、正誤判定、得点、レース終了、再挑戦の処理
README.txt       この説明書

■ 問題を追加・編集する
js/questions.jsをテキストエディタで開き、questions配列の中に問題を追加します。
各問題には、ほかと重ならないid、prompt（問題文）、choices（選択肢2つ）、correctValue（正解の数値）、explanation（解説）を設定します。
選択肢は基本2つです。choicesのvalueとcorrectValueは数値として一致させてください。labelは画面に表示する文字です。
例：問題文を「3 ＋ 2 ＝ ？」、選択肢を「4」と「5」、correctValueを5にする。
1レースの出題数は、同じファイルのgame.questionsPerRaceで変更できます。問題数より大きい値を指定しても、登録されている問題数まで出題されます。

■ 見た目を変更する
css/style.cssを編集します。色はファイル冒頭の:rootにある変数から変更できます。
車やコースの形、選択肢の位置、スマートフォンでの表示、アニメーションもこのファイルで調整します。

■ 動作確認
index.html、cssフォルダ、jsフォルダは同じ階層に置いてください。
ファイル名・フォルダ名の大文字小文字を変えると、GitHub Pagesなどで読み込みに失敗する場合があります。
変更後はブラウザを再読み込みし、スタート、左右の選択、全問終了、再挑戦を確認してください。
