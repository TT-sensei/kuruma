くるまスタディ・サーキット
==========================

■ このゲームについて
GT系レーシングカーで国語・算数の2択問題に挑戦します。
全200問。ことばや計算を、生活の場面と結びつけて練習できます。

■ 遊び方
1. index.htmlをブラウザで開き、車・教科・問題レベルを選びます。
2. コースは5種類からランダムに選ばれます。
3. 正解すると時速が上がり、不正解だと時速が下がります。
4. 道路中央のラインは速度に合わせて流れます。
5. 左右の答えから選びます。← / →キー、A / Dキーでも選べます。

■ 問題の内容
国語：交通、買い物、健康、安全、学校、機器の利用など、生活で目にする漢字の読み。
算数：かけ算を多めに、たし算・ひき算も収録。わり算は少数で、あまりのあるわり算はありません。
問題は基本2択で、短い解説が表示されます。

■ ファイル構成
index.html       画面の骨組み、車・教科・問題レベルの選択
css/style.css    車4種類、コース5種類、速度に連動するアニメーション
js/questions.js  全200問の問題データ
js/game.js       出題、速度変化、正誤判定、得点、ゴール処理
README.txt       この説明書

■ 問題を追加・編集する
js/questions.jsのquestions配列に問題を追加します。
gradeは1=基礎、2=標準、3=チャレンジです。問題文と解説は、子ども扱いする言い回しを避け、短く具体的にしてください。
