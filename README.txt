くるまスタディ・サーキット
==========================

■ このゲームについて
好きな車を選び、国語・算数の2択問題に挑戦する学習ゲームです。
小学1〜3年生程度の問題を収録しています。1レースは最大8問です。
外部ライブラリや通信は使いません。

■ 遊び方
1. index.htmlをブラウザで開きます。
2. レーシングカー・パトカー・しょうぼうしゃ・トラックから車を選びます。
3. 国語・算数、学年の目安を選びます。
4. コースは5種類からレースごとにランダムで選ばれます。
5. 正しい答えを選ぶと時速が上がり、まちがえると時速が下がります。道路のラインも速さに合わせて流れます。
6. 左右の答えから選択します。← / →キー、A / Dキーでも選べます。
7. ゴール画面で正解数を確認し、再挑戦できます。

■ ファイル構成
index.html       画面の骨組み、車・教科・学年の選択、時速表示
css/style.css    車4種類、コース5種類、速度連動アニメーション、画面表示
js/questions.js  国語・算数の問題文、選択肢、正解、解説
js/game.js       車・コースの反映、出題、速度変化、正誤判定、得点、ゴール処理
README.txt       この説明書

■ 問題を追加・編集する
js/questions.jsのquestions配列に問題を追加します。
subjectは「国語」または「算数」、gradeは1〜3、topicは単元、promptは問題文、choicesは基本2つの選択肢、correctValueは正解のvalue、explanationは解説です。
選択肢のvalueは正解判定に使い、labelは画面に表示する文字です。
教科・学年の選択に応じて、条件に合う問題から出題します。1レースの問題数はgame.questionsPerRaceで変更できます。

■ 見た目を変更する
css/style.cssを編集します。車の色・形は .car--race / .car--police / .car--fire / .car--truck、コースは .course-grand-prix / .course-city / .course-forest / .course-coast / .course-night を編集します。
