くるまスタディ・サーキット
==========================

■ このゲームについて
車を選び、コースを走りながら国語・算数の2択問題に挑戦する学習ゲームです。
小学1〜3年生程度の問題を収録しています。1レースは最大8問です。
HTML / CSS / JavaScriptだけで動き、外部ライブラリや通信は使いません。

■ 遊び方
1. index.htmlをブラウザで開きます。
2. レーシングカー・パトカー・しょうぼうしゃ・トラックから好きな車を選びます。
3. 学習する教科（国語＋算数／国語／算数）と学年の目安を選びます。
4. 「レース スタート！」を押すと、5種類のコースからランダムに決まります。
5. 左右の答えから正しい方を選びます。← / →キー、A / Dキーでも選べます。
6. ゴール画面で正解数を確認し、「もう一度走る」で再挑戦します。

■ ファイル構成
index.html       画面の骨組み、車の選択、教科・学年の選択
css/style.css    車4種類、コース5種類、画面サイズ、ボタン、アニメーション
js/questions.js  国語・算数の問題文、選択肢、正解、解説
js/game.js       車・コースの反映、出題、左右の選択、正誤判定、得点、ゴール処理
README.txt       開き方と編集方法

■ 問題を追加・編集する
js/questions.jsをテキストエディタで開き、questions配列の中に問題を追加します。
各問題には、重ならないid、subject（国語または算数）、grade（1〜3）、topic（単元）、prompt（問題文）、choices（基本2つの選択肢）、correctValue（正解のvalue）、explanation（解説）を設定します。
選択肢のvalueは正解判定に使い、labelは画面に表示する文字です。国語は文字列、算数は数値のvalueを使えます。
1レースの出題数はgame.questionsPerRaceで変更できます。教科と学年の選択に応じて、条件に合う問題から出題されます。

■ 見た目を変更する
css/style.cssを編集します。車の色・形は .car--race / .car--police / .car--fire / .car--truck、コースの背景は .course-grand-prix / .course-city / .course-forest / .course-coast / .course-night のCSSを編集します。
車やコースを追加するときは、js/game.jsのvehiclesまたはcoursesの設定とCSSの両方を更新します。

■ 動作確認
index.html、cssフォルダ、jsフォルダは同じ階層に置いてください。
ファイル名・フォルダ名の大文字小文字を変えると、GitHub Pagesなどで読み込みに失敗する場合があります。
変更後は、車の選択、教科と学年の切り替え、コースのランダム変更、全問終了、再挑戦を確認してください。
